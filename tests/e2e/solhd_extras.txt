# Solitaire HD v1.1 extras end to end: the Game menu's Hint (H), Finish (F6) and Statistics (F4); the
# Options dialog's Extras group (off by default, written to HKCU\Software\xp-cards\Solitaire HD, kept
# across restarts); the hint's flash (the source, then the destination, captured mid-flash); single
# click to move (and its double-click ignored); turning cards over automatically (+5 each, as a click);
# the statistics (reset, a loss, wins, the dialog's text); save on exit and resume at start-up; Finish
# by hand and automatically after a winning line; the unwinnable warning and winnable deals only.
# Run by tests/e2e/run_solhd_e2e.sh.
#
# Geometry and deal 64 as solhd_smoke.txt: client 1264 x 854 (cards 153 x 207; columns x = 24 201 378
# 555 732 909 1086, tableau top y = 231, steps 6 / 32; stock 24,10, waste 201,10, foundations x = 555 732
# 909 1086, y = 10). Deal 64: col 1 AH, col 2 #7H 4S, col 3 # # TD, col 4 # # # KC, col 5 # # # # 5D,
# col 6 # # # # # AC, col 7 # # # # # # 2H. Ids (res/solitaire/resource.h): 1102 Hint, 1103 Finish,
# 1104 Statistics; dialog 103 Options (Extras 321 AutoTurn, 322 ClickToMove, 323 AutoFinish,
# 324 WinnableOnly, 325 SaveGame, 326 WarnUnwinnable); 105 Statistics (330 mode, 332 values, 333 Reset).
#
# The winning line of deal 64 (Draw Three) is the full-information solver's, played through the
# session and turned into clicks and drags by tests/solitaire/sol_e2e_line.c ("64 3"): 152 actions to
# the first position where Finish is possible (the stock and the waste used up, every card face up).

# FreeCell HD v1.2 extras end to end (the solver): Hint (key H) on game #1 - the source card flashes
# inverted twice, then the destination (here an empty free cell) twice, captured mid-flash, with nothing
# moved or selected afterwards; following the hint, the next one comes at once (the cached solution).
# The unwinnable warning (Options > Extras): game #1 made unwinnable in three moves warns once, a fourth
# move does not, Undo back to a winnable position and Redo warns again; the deal #11982 "cannot be
# won"; Hint there says "There are no more winning moves.". Finish (F6) is grayed until the position is
# a sure win, reached without the cheat by playing the solver's line for game #31364 (generated
# natively with src/core/solver.c and embedded below; the first 21 moves, no MoveCol dialog); Finish
# by hand is one move, "Finish automatically" finishes right after the 21st move and is not a move.
# The two Options and their registry values survive a restart.  Run by tests/e2e/run_fchd_e2e.sh.
# The client is 1264 x 854, exactly scale 2 (columns x = 14 170 326 482 639 795 951 1107, first card
# y = 212, step 37, cards 142 x 192; free cells x = 0 142 284 426, home cells x = 696 838 980 1122,
# y 0..191). Clicks: a column at (x + 71, 220), a top-row cell at its centre (x + 71, 96).

timeout 60000
